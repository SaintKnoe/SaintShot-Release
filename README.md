# SaintShot 下载

SaintShot 是 macOS 原位截图和标注工具。支持区域与窗口截图、文字识别和系统翻译、滚动截图、马赛克、钉图，以及复制或保存图片。

## 下载

[下载最新版本](https://github.com/SaintKnoe/SaintShot-Release/releases/latest)

当前版本：0.2.23。需要 macOS 14 或更新版本；系统翻译需要 macOS 15 或更新版本。

下载 DMG 后，将 SaintShot 拖入“应用程序”文件夹再打开。首次使用截图需要允许屏幕录制权限。

## 当前分发说明

此版本采用临时签名，尚未经过 Apple 开发者签名和公证。macOS 可能阻止首次启动；请在系统设置的“隐私与安全性”中选择仍要打开。升级后可能需要重新授权屏幕录制权限。

0.2.19 起支持应用内自动更新与手动检查更新。0.2.18 及更早版本需要先手动安装本版。
